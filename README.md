# 🤝 MeetAI: Intelligent Meeting Platform

A next-generation meeting platform powered by AI, designed to enhance productivity and streamline digital collaboration. Built with the latest tech stack for maximum performance and scalability.

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **Next.js 15** | Latest React framework with Server Actions |
| **Drizzle ORM** | Type-safe database interactions |
| **TypeScript** | Strict typing for enterprise-grade code |
| **Shadcn UI** | Accessible and customizable UI components |
| **PostCSS** | Advanced CSS processing |

---

## ✨ Key Features

- 🧠 **AI Assistance**: Intelligent meeting summaries and action items.
- ⚡ **Next-Gen Speed**: Leverages Next.js 15 and server-side rendering.
- 🎨 **Modern Design**: Sleek, minimalist UI using Shadcn/ui components.
- 🛡️ **Robust Data**: Safe and efficient data management with Drizzle ORM.
- 📱 **Cross-Platform**: Fully responsive experience for mobile and desktop.

---

## 🚀 Getting Started

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/Sirius6907/meetai1.git
   ```
2. Navigate to project:
   ```bash
   cd meetai
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run development server:
   ```bash
   npm run dev
   ```
