# 🤝 MeetAI

An AI-powered collaboration and meeting platform built for the modern remote work era. MeetAI leverages advanced intelligence to enhance the way teams connect.

## 🚀 Key Features

- **AI Summarization**: Automatically generate meeting highlights and action items.
- **Real-time Collaboration**: Integrated tools for seamless team interaction.
- **High Performance**: Built on Next.js 15 for lightning-fast page transitions and SEO.
- **Enterprise UI**: Scalable and professional design system.

## 🛠️ Built With

- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Architecture**: Specialized sub-packages (Monorepo-style) for backend and core meeting logic.

## 🚦 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```
2. **Start Dev Server**:
   ```bash
   npm run dev
   ```
